# 05 · 界面与交互规范

> 小方工作室 · Chit ｜ 立项阶段 ｜ 2026-10-06
> 一句话原则：**界面是原生 Win32 控件，不是网页。越像系统自带的东西越好。**

---

## 一、总体基调

Chit 的界面目标不是「好看」，是**不碍事**。

它是那种用户一天打开二十次、每次只待十秒的工具。所以：

- **没有启动画面。** 双击就出窗口，不显示 logo、不显示加载动画。
- **没有欢迎页。** 空白文档就是空白，不放模板、不放最近文件墙、不放「开始使用」。
- **没有首次向导。** 不弹「选择你的偏好」、不问「是否设为默认」、不问「是否发送统计」。
- **没有横幅、没有推广、没有「升级到 Pro」。**
- **界面语言 100% 中文。**

**判据：** 如果截图看起来像一个网页或一个 App，就是做错了。Chit 的截图应该像一个**系统附件**。

## 二、配色

**只用系统语义色，不引入配色系统。**

| 角色 | 取值 |
| --- | --- |
| 窗口背景 | 系统窗口色（`COLOR_WINDOW`）／深色模式下深灰 |
| 文本前景 | 系统窗口文本色（`COLOR_WINDOWTEXT`） |
| 系统菜单、滚动条、边框 | **一律用系统原生绘制**，不重绘 |
| 选区背景 | 系统高亮色（`COLOR_HIGHLIGHT`） |
| 行号栏 | 比背景略深一档，文本用次要文字色 |
| 当前行高亮 | 背景色提亮约 3%，**不显眼** |
| 查找命中 | 1px 描边，不用刷底色 |
| 制表符 / 空格可视标记 | 次要文字色 |

**明确禁止：**

- **禁止品牌色。** Chit 不用小方的浅绿、不用小方的蓝。它是系统附件，不给它上品牌。
- 禁止紫色、禁止渐变、禁止阴影、禁止圆角卡片、禁止 SVG 图标。
- 禁止自定义主题皮肤系统。

**深色模式：** 三态（跟随系统 / 强制深色 / 强制浅色）。深色下背景约 `#1E1E1E`、文本约 `#D4D4D4`，**只用两组中性色，不加第二强调色**。

## 三、窗口结构

```
┌──────────────────────────────────────────────────────────┐
│ 菜单栏  文件 编辑 查找 查看 工具 帮助                        │  原生菜单
├──────────────────────────────────────────────────────────┤
│ 标签栏  [ a.txt ×] [ 日志.log * ×] [ + ]                  │  1 行，超宽横向滚动
├──────────────────────────────────────────────────────────┤
│                                                          │
│  编辑区（行号栏 + 文本区）                                  │
│                                                          │
├──────────────────────────────────────────────────────────┤
│ 状态栏  行 12, 列 34  |  UTF-8  |  CRLF  |  1,204 字符      │  1 行，各段可点击
└──────────────────────────────────────────────────────────┘
```

**没有工具栏。** 所有动作在菜单和快捷键里。工具栏是给功能密集的软件用的，Chit 不是。

**没有侧边栏、没有文件树、没有大纲。** 这些都要占内存和启动时间。

## 四、窗口尺寸与记忆

| 项 | 规格 |
| --- | --- |
| 默认尺寸 | 900 × 640 |
| 最小尺寸 | 480 × 320 |
| 位置与尺寸 | 记住上次的，但**越界时拉回屏幕内** |
| 标题栏 | `文件名 — Chit`；未保存时前缀 `* `；无文件时 `无标题 — Chit` |
| 最大化 / 全屏 | 支持；`F11` 全屏 |
| 任务栏图标 | 单实例；重复启动把已有窗口带到前台 |

## 五、菜单结构

**原则：最多两层。** 找不到的功能等于不存在。

| 菜单 | 项 |
| --- | --- |
| **文件** | 新建 / 打开… / 最近打开 ▸ / 保存 / 另存为… / **编码 ▸**（以…重新解释｜转换为…）/ **换行符 ▸**（CRLF｜LF｜CR）/ 打印… / 属性 / 退出 |
| **编辑** | 撤销 / 重做 / 剪切 / 复制 / 粘贴 / 删除 / 全选 / **行操作 ▸**（删除行｜上移｜下移｜复制行）/ **空白字符 ▸**（显示 Tab｜显示行尾空白｜删除行尾空白）/ 转换缩进 ▸ |
| **查找** | 查找… / 替换… / 查找下一个 / 查找上一个 / 转到行… |
| **查看** | 行号 / 自动换行 / 标尺 ▸ / 高亮当前行 / 只读模式 / **主题 ▸**（跟随系统｜深色｜浅色）/ 放大 / 缩小 / 重置缩放 / 全屏 |
| **工具** | **文件关联…** / 会话与恢复 ▸ / 草稿目录 / 清空最近记录 / 设置… |
| **帮助** | 快捷键一览 / 关于 Chit |

**注意：**「编码」和「换行符」直接放在**文件**菜单下，不要太深。这是用户从记事本换过来的最大理由，必须两下点到。

## 六、状态栏

单行，分段显示，**每段都能点**：

| 段 | 内容 | 点击行为 |
| --- | --- | --- |
| 1 | `行 12, 列 34` | 打开「转到行」 |
| 2 | `UTF-8` / `GB18030` / `UTF-16 LE` 等 | 弹出编码菜单 |
| 3 | `CRLF` / `LF` / `CR` | 弹出换行符菜单 |
| 4 | `1,204 字符` 或 `选中 34 字符 / 51 字节` | 打开字符统计 |
| 5 | `大文件模式` / `只读` / `已修改` | —— |

**没有进度条**，除了大文件载入时在状态栏右侧显示一个细进度与「取消」。

## 七、对话框

Chit 的对话框**越少越好**。目前只允许这几个：

| 对话框 | 触发 |
| --- | --- |
| 打开 / 另存为 | 系统文件选择框（**用系统原生的**，不自绘） |
| 字体 | 系统字体选择框（**用系统原生的**） |
| 查找替换 | **非模态，贴在窗口底部**，不弹独立窗口 |
| 转到行 | 一行输入框 |
| 未保存提示 | 保存 / 不保存 / 取消 |
| 编码转换警告 | 列前 20 处无法表示的字符 |
| 外部修改冲突 | 重新载入 / 覆盖 / 取消 |
| 关于 | 版本、许可证、仓库地址、**一行字说明「本程序不联网、不收集任何数据」** |

**所有对话框用系统原生样式。** 不自绘、不加圆角、不加动画。

## 八、交互细节

| 场景 | 行为 |
| --- | --- |
| 拖文件进窗口 | 拖到编辑区 = 插入路径文字；拖到标签栏 = 打开为标签 |
| 双击标签 | 关闭该标签 |
| 中键点标签 | 关闭该标签 |
| `Ctrl+滚轮` | 缩放字号 |
| 滚轮 | 上下滚三行 |
| `Ctrl+-` 关联 | 缩放视角 |
| 长按 `Alt` | 显示菜单访问键下划线 |
| 空白文档 + `Ctrl+S` | 弹另存为，**不报错** |
| 打开不存在的文件 | 中文提示「找不到该文件」，**不白屏、不英文堆栈** |

**焦点环：** 用系统默认的虚线焦点框，不自绘。

**动画：** **一个都没有。** 不淡入、不滑动、不弹跳、不旋转加载图标。行号栏滚动与文本同步靠直接重绘。

## 九、快捷键总表

见 [docs/02](02-功能规格.md) 第三节。原则：

- **优先与 Windows 记事本、Windows 通用习惯一致**，让用户不用学。
- 冲突时以系统习惯优先（`Ctrl+W` 关标签、`Ctrl+F` 查找、`F3` 下一个）。
- 「帮助 → 快捷键一览」里要能查到全部快捷键，**用静态文本，不用网页**。

---

## 十、无障碍与系统一致性

- 全部控件有访问键（`Alt+F` 打开文件菜单）。
- 全部控件在 Windows Narrator 下可读。
- 支持高对比度主题（跟随系统）。
- 支持 `Ctrl+滚轮` 之外的系统缩放。
- 支持 `DPerMonitorV2` 多显示器 DPI 感知，**不模糊**。
- 遵循系统「动画效果」开关（我们本来就没有动画，天然合规）。
- 遵循系统浅色 / 深色偏好。

---

## 十一、交付前界面自检

- [ ] 没有启动画面、没有欢迎页、没有首次向导
- [ ] 没有工具栏、没有侧边栏
- [ ] 没有品牌色、没有渐变、没有阴影、没有圆角卡片、没有自制图标
- [ ] 没有一行动画
- [ ] 菜单最多两层
- [ ] 编码与换行符在文件菜单下，两步可达
- [ ] 状态栏各段可点击
- [ ] 查找替换是底部嵌入式，不是独立窗口
- [ ] 所有对话框是系统原生样式
- [ ] 界面上没有英文残留
- [ ] 多显示器下不模糊
- [ ] 高对比度模式下可读
