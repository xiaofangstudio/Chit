# 02 · 功能规格

> 小方工作室 · Chit ｜ 立项阶段 ｜ 2026-10-06
> 原则：**每加一个功能，都要先过「轻量三关」**——不影响冷启动、不影响磁盘体积、不引入常驻。

## 二、模块 A · 文件

### A1 新建

- `Ctrl+N` 新建空白文档，默认编码 UTF-8（无 BOM），换行符 CRLF。
- 新建时**不弹任何对话框**。

### A2 打开

- `Ctrl+O` 打开系统文件选择框，支持多选。
- 支持**拖拽打开**：把文件拖到窗口或标签栏即打开；拖到托盘（若开启预热）不处理。
- 支持**命令行打开**：`Chit.exe "D:\a.txt"`、`Chit.exe a.txt b.txt`（多文件开多标签）。
- 支持**用 Chit 打开**（文件关联生效后双击即打开），见 [docs/06](docs/06-文件关联与系统集成.md)。
- 无 BOM 的 UTF-8 与非 UTF-8 文件，按下面的探测规则处理。

### A3 编码探测规则

按顺序尝试，**只要有一步能无歧义解码成功就停下**：

1. 有 BOM → 直接用 BOM 声明的编码（UTF-8 BOM / UTF-16 LE / UTF-16 BE，优先级最高）。
2. 严格 UTF-8 校验：整段字节序列符合 UTF-8 且无非法序列 → 判为 UTF-8。
3. 中文环境启发式：按 GB18030 解码，若解出字符落在常用汉字 + 中文标点区间且无替换符 → 判为 GB18030。
4. 上述全失败 → 按系统 ANSI 代码页（中文 Windows 为 GBK）解码，并在状态栏标注「ANSI」。

> **不许静默改编码。** 探测结果只是「本次打开按这个编码解释」，保存时默认沿用原编码，只有用户主动转换才改变文件编码。

### A4 保存

- `Ctrl+S` 保存；未命名文件保存时弹「另存为」。
- `Ctrl+Shift+S` 另存为。
- **保存时不改编码、不改换行符**，除非用户主动转换过。
- 保存时保留原有的 BOM 状态（原本有 BOM 就保留，原本没有就不加），除非用户主动转换过。
- **原子写入：** 先写临时文件再替换，避免写入过程中崩溃导致原文件损坏。
- 外部修改检测：文件被其他程序改动且磁盘版本与内存版本不一致时，**提示用户**，不静默覆盖、不静默重载。

### A5 最近文件

- 菜单「文件 → 最近打开」保留最近 10 个。
- 记录存 ini 文件，不写注册表（绿色版友好）。
- 有一个「清空最近记录」项。

## 三、模块 B · 编辑

| 功能 | 快捷键 |
| --- | --- |
| 撤销 | `Ctrl+Z` |
| 重做 | `Ctrl+Y` / `Ctrl+Shift+Z` |
| 剪切 / 复制 / 粘贴 | `Ctrl+X` / `Ctrl+C` / `Ctrl+V` |
| 全选 | `Ctrl+A` |
| 删除整行 | `Ctrl+Shift+K` |
| 上移 / 下移当前行 | `Alt+↑` / `Alt+↓` |
| 复制当前行 | `Ctrl+D` |
| 行首 / 行尾 | `Home` / `End` |
| 文档首 / 文档尾 | `Ctrl+Home` / `Ctrl+End` |
| 缩进 / 反缩进 | `Tab` / `Shift+Tab`（有选区时） |
| 转换 Tab ↔ 空格 | 菜单「编辑 → 空白字符」 |

**撤销栈无实际上限**，直到内存预算触顶才从最旧的一端裁剪。**撤销栈随标签页独立。**

**行尾空白处理**（菜单「编辑 → 行尾空白」）：

- 删除行尾空白（当前行 / 全部行）。
- 行尾空白可视化（显示为细点）。
- Tab 可视化（显示为箭头）。

## 四、模块 C · 标签页

- 一个标签页 = 一个文档。**标星号 `*` 表示有未保存改动。**
- 关闭标签：`Ctrl+W`。有未保存改动时提示「保存 / 不保存 / 取消」。
- 恢复刚关掉的标签：`Ctrl+Shift+T`（按关闭栈倒序）。
- **拖拽重排**标签顺序。
- 标签栏右键菜单：关闭 / 关闭其他 / 关闭右侧全部 / 复制路径 / 在资源管理器中显示。
- 标签过多时标签栏可横向滚动，**不换行**（换行会挤压编辑区）。

---

## 五、模块 D · 查找替换

**查找（`Ctrl+F`）**：从光标处向下找，循环。找到后高亮所有匹配项（描边高亮，不是刷底色）。

**替换（`Ctrl+H`）**：替换 / 全部替换。全部替换后提示「已替换 N 处」（状态栏提示，不弹窗）。

**选项：**

- 大小写敏感。
- 全词匹配。
- 正则表达式（`Ctrl+R` 切换）。
- 循环查找。
- 搜索范围：当前标签 / 所有打开的标签（下拉选择）。
- 「在文件中查找」首版**不做**（要做也得先证明不拖慢启动）。

**正则引擎：** 用底座已有的引擎，**不引入新的正则库**。支持捕获组反向引用 `$1`。

## 六、模块 E · 编码与换行（Chit 的招牌功能）

这是用户从记事本换过来最直接的收益点，必须做扎实。

### E1 编码

- 状态栏常显当前编码，点击可切换。
- 支持的编码：`UTF-8` / `UTF-8 BOM` / `UTF-16 LE` / `UTF-16 BE` / `GB18030` / `GBK` / `Big5` / `Shift-JIS` / `Latin-1` / 系统 ANSI。
- 两种操作，必须分清楚：
  - **「以……重新解释」**（Reinterpret）——不改字节，只换解码方式。用于**修乱码**。
  - **「转换为……」**（Convert）——改变字节，下次保存写新编码。
- 转换前提示一次：「此操作会改变文件内容，保存后不可撤销」。
- **有损转换保护：** 若目标编码无法表示某些字符（如把带 emoji 的文本转 GBK），必须列出无法转换的字符并让用户确认，**不许静默替换成 `?`**。

### E2 换行符

- 状态栏常显当前换行符（`CRLF` / `LF` / `CR`），点击可切换。
- 打开时可以自动探测（统计三种换行的出现次数，多数者为准）。
- 转换：`CRLF` / `LF` / `CR` 三选一，对整个文件生效。

### E3 字符与字节查询

- 状态栏显示：行号、列号、选中字符数、选中字节数。
- 菜单「视图 → 字符统计」：字符数、字数、行数、字节数（按当前编码算）。

## 七、模块 F · 视图

| 项 | 说明 |
| --- | --- |
| 行号 | 显示 / 隐藏，独立于自动换行 |
| 自动换行 | 开 / 关。开启时行号栏连续编号 |
| 字号缩放 | `Ctrl+滚轮` / `Ctrl+加号` / `Ctrl+减号` / `Ctrl+0` 复位，范围 8–36 |

| 深色模式 | 三态：跟随系统 / 强制深色 / 强制浅色 |
| 全屏 | `F11` |
| 标尺 | 40 / 80 / 120 列竖线，可开关 |
| 高亮当前行 | 淡淡的背景色，可关 |
| 只读模式 | 防误改，可开关 |

**明确不做：** 语法高亮、代码折叠、缩略图、多个编辑区。

## 八、模块 G · 大文件模式

**触发阈值：文件大于 20 MB 时询问用户，大于 100 MB 时默认进入大文件模式。**

进入后：

- 只把**视口附近的内容**载入内存（窗口 ± N MB，N 可调，默认 4 MB），滚动时按块换入换出。
- 关闭全文索引：查找只能从当前视口向下顺序扫描，并显示进度。
- 关闭行号的高亮当前行等装饰。
- 关闭撤销的全文快照（改为块级撤销）。
- 状态栏明确标注「大文件模式」。

**红线：无论文件多大，打开时窗口必须先出来，载入在后台线程做，界面不许假死。** 载入期间显示进度条与「取消」按钮。

## 九、模块 H · 会话与恢复

- **会话恢复：** 退出时记录打开的文件列表与光标位置；下次启动时若上次是非正常退出，或用户设置了「启动时恢复上次会话」，则恢复。
- 勾选项（默认关闭）：「退出时保存会话」、「启动时恢复上次会话」。
- **自动草稿：** 未保存的改动每 30 秒写一个草稿到 `%LOCALAPPDATA%\Chit\drafts\`，正常保存或正常关闭即删除。**只在非正常退出后才会被用上。**
- 草稿目录有体积上限（默认 16 MB），超出从最旧删起。
- 崩溃后启动时，若有草稿残留，提示「上次未正常退出，是否恢复未保存的内容？」。

> 这一模块是唯一允许 Chit 往磁盘上写「用户没主动要求写的东西」的地方，**必须做得完全透明**：草稿目录路径写在设置里、放在「打开草稿目录」按钮旁边、允许一键关闭该功能。

## 十、模块 I · 系统集成

详见 [docs/06-文件关联与系统集成.md](06-文件关联与系统集成.md)。摘要：

- 注册 ProgID，让 Chit 出现在「打开方式」列表里。
- 引导用户到 Windows「默认应用」页面把 Chit 设为默认。
- 关联的扩展名由用户勾选：`.txt` / `.log` / `.ini` / `.cfg` / `.csv` / `.json` / `.xml` / `.md` / `.sql` / `.yaml` / `.bat` / 自定义。
- 默认只勾 `.txt` 与 `.log`，**其余一律用户主动勾选**。
- 提供「移除所有关联并还原默认程序」。

## 十一、设置项汇总

设置存在 `%APPDATA%\Chit\config.ini`（绿色版则存在 exe 同目录）。**全部设置项不超过一屏，不做多页设置窗口。**

- 启动：是否恢复上次会话；是否显示最近文件。
- 编辑：Tab 宽度；是否用空格替代 Tab；行尾空白处理；自动缩进。
- 编码：默认新建文件编码；默认换行符；是否显示 BOM 提示。
- 视图：字体与字号；主题（跟随系统 / 深色 / 浅色）；行号；自动换行；标尺列宽。
- 性能：大文件阈值；是否启用预热常驻（**默认关，开启时文案必须写明代价**）。
- 系统：文件关联管理；开机启动（**默认关，且默认项就是关**）。
- 隐私：草稿功能开关；打开草稿目录；清空最近记录；**「联网」项不存在，因为程序不联网**。
