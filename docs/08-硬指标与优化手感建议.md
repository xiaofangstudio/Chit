# 08 · 硬指标、优化建议与手感建议

> 本文是 Chit 的补充文档。硬指标与 [04-资源占用预算.md](04-资源占用预算.md) 完全对齐，冲突时以 `04` 为准。

## 一 硬指标

全部为可测量值。测不出来的一律不算，也不许用「约」「左右」这类模糊说法。

| 项 | 指标 | 测法 |
| --- | --- | --- |
| 冷启动到可输入 | ≤ **100ms** | `04` 第六节脚本，取 10 次中位数 |
| 安装后磁盘占用 | ≤ **3MB** | 安装目录递归求和 |
| 绿色版体积 | ≈ 1MB | 解压即用，不写注册表 |
| 后台占用 | **0 KB** | 关窗后 `Get-Process -Name Chit` 输出为空 |
| 空文档应用自身堆 | ≤ **10KB** | 口径 C，见 `04` 第一节 |
| 空文档私有工作集 | ≤ 2MB | 任务管理器 |
| 1MB 文本 | ≤ 6MB | |
| 100MB 文本 | ≤ 200MB | 走大文件模式 |
| 空文档线程数 | ≤ 4 | |
| 常驻线程 | **0** | |
| 联网请求 | **0** | 防火墙挂一周 |
| 交付体积 | ≤ 3MB（生态约束上限为 112.5MB，本产品远低于） | |

**生态体积规则：** Reelix 是体量天花板（150MB），除 Reelix 外任何产品不得超过它的 3/4，即 112.5MB。Chit 按更严的 3MB 执行。

## 二 优化建议

### 2.1 启动路径

1. **启动路径上不读配置以外的任何文件。** 词典、字体、图标主题、语言包全部延后到首次使用时加载。
2. **不做任何启动期磁盘扫描。** 会话恢复只读一个索引文件，不遍历目录。
3. **窗口先显示再填充内容。** 让用户先看到界面，文本在窗口可见之后再载入。
4. **不预热 JIT，不装运行时。** 原生 Win32 直出，这是 100ms 的前提。

### 2.2 文本模型

5. **大文件模式只载入视口窗口。** 超过阈值时不建全文索引，滚动到哪里读到哪里。
6. **撤销栈用差分存储。** 只存被改动的片段与位置，不存整份文档快照。
7. **编码检测只读文件头部若干 KB。** 不做全文件扫描，检测不出来时给用户手动选择的入口。
8. **空文档不分配大块缓冲。** 初始块按需增长，这是口径 C 能压到 10KB 的关键。

### 2.3 渲染与内存

9. **只重绘脏行。** 光标移动与输入只触发受影响行的重绘。
10. **语法高亮按可见行计算并缓存**，滚动时复用缓存。
11. **不使用任何带 GC 或带 VM 的语言。** 一次 GC 停顿就能让 100ms 的启动预算失控。
12. **图标与资源进 exe 资源节**，不散落成外部文件。

### 2.4 退出与清理

13. **关窗即退，不留后台线程、不留隐藏窗口。**
14. **卸载时先删注册表项再删文件**，文件关联删除并把默认程序还给用户原来的选择。

## 三 手感建议

### 3.1 打开与关闭

1. **冷启动必须体感为「点一下就开」。** 100ms 是硬指标，不是目标。
2. **关窗不弹确认框。** 有未保存内容时才提示，且默认聚焦「保存」。
3. **支持拖拽文件到窗口打开**，多文件拖入直接开成多标签。
4. **双击空白区域不做任何事。** 不要塞广告位或功能推荐。

### 3.2 编辑

5. **`Ctrl+S` 保存、`Ctrl+Shift+S` 另存、`Ctrl+W` 关标签、`Ctrl+Tab` 切标签。** 与主流一致，不做自创键位。
6. **状态栏常驻显示编码与换行符**，点击即可切换。
7. **查找替换的输入框带历史记录**，上下键翻历史。
8. **正则替换要能实时预览匹配数**，不点「全部替换」也能看到会改多少处。
9. **多标签拖拽重排，中键点标签即关闭。**
10. **列编辑模式用 `Alt` 加拖动进入**，不要藏在三级菜单里。

### 3.3 大文件

11. **打开大文件先出窗口再载入**，进度显示在状态栏，不弹模态对话框。
12. **大文件模式下明确提示当前处于简化模式**，并说明哪些功能不可用。
13. **打开 1GB 文件时界面不假死**，滚动与光标移动始终可用。

### 3.4 反馈与错误

14. **编码检测失败时给中文提示并让用户手动选择**，不要静默按 ANSI 打开导致乱码。
15. **保存失败要说清原因与路径**，例如「目标文件被其他程序占用，请关闭后重试」。
16. **任何提示都不带「请」开头的客套话。** 直接说事：「保存文件」而不是「请保存您的文件」。
