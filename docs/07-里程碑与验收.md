# 07 里程碑与验收

本文把 Chit 从零到可发布拆成 5 个里程碑。**每个里程碑都有明确的可验证产出，验收不通过不进下一个。**

排序原则：
- **先能跑，再能编，再能快，再接系统，最后交付。**
- **M1 之前不碰文件关联**（基础编辑都不稳，谈什么默认打开）。
- **M2 之前不碰大文件优化**（先保证小文件正确，再谈 1GB）。
- **任何阶段都不许破坏零常驻、零联网、冷启动。**

---

## 一、里程碑总览

| 里程碑 | 主题 | 一句话目标 | 关键验收 |
| --- | --- | --- | --- |
| M0 | 骨架 | 能开、能编、能存，体积与速度达标 | 冷启动中位数 ≤100ms、安装 ≤3MB、后台 0 进程 |
| M1 | 编辑 | 功能多到能弃用 Windows 记事本 | 多标签 + 编码 + 换行 + 查找替换全部可用 |
| M2 | 快 | 大文件不卡、断电能恢复 | 100MB 秒开、崩溃不丢草稿 |
| M3 | 集成 | 双击真能用，且不流氓 | 「打开方式」出现、默认应用可设、干净卸载 |
| M4 | 交付 | 能给别人装 | 安装包 + 卸载验证 + 绿色版 |

---

## 二、M0 骨架

### 目标
底座跑通，窗口能开，能新建/打开/保存纯文本，且**第一版就把三个数字做达标**。

### 任务
1. clone Notepad4 源码，改名 `Chit.exe`，跑通 CMake + MSVC 构建，产出**单文件 exe**。
2. 关闭底座自带的常驻/托盘/更新等功能，**改成关闭窗口即完全退出**。
3. 走通最小闭环：新建 → 输入 → 保存 → 打开 → 显示。
4. 加编码探测四步（BOM → 严格 UTF-8 → GB18030 启发式 → 系统 ANSI）。
5. 加原子写入（临时文件 + `ReplaceFileW`），绝不原地覆盖。
6. 保留 Notepad4 / Notepad2 / Scintilla 三份许可证原文到 `licenses/`。
7. 接上构建期零联网符号扫描（`docs/03` 5.5）。

### 验收
| 项 | 判据 |
| --- | --- |
| 冷启动 | 10 次 `Measure-Command` 取中位数 **≤100ms** |
| 安装体积 | 安装目录 **≤3MB** |
| 后台占用 | 关闭窗口后 `Get-Process -Name Chit` **无输出** |
| 零联网 | 构建期扫描通过，二进制无网络符号 |
| 许可证 | `licenses/` 下三份原文齐全 |
| 文本正确 | 打开一个中文 GBK 文件不乱码 |

**M0 不过关，不写任何新功能。**

---

## 三、M1 编辑

### 目标
功能多到能让用户把 Windows 默认记事本丢到一旁。

### 任务
1. **多标签**：`*` 未保存标记、`Ctrl+W` 关闭、`Ctrl+Shift+T` 恢复、拖拽重排、超宽横向滚动不换行。
2. **编码**（招牌功能）：
   - 识别 UTF-8 / UTF-8 BOM / UTF-16 LE / UTF-16 BE / GB18030 / GBK / Big5 / Shift-JIS / Latin-1 / 系统 ANSI。
   - **「以……重新解释」（修乱码，不改字节）** 与 **「转换为……」（改字节）** 分清。
   - 有损转换保护：列前 20 处无法表示的字符让用户确认，**不许静默替换成 `?`**。
   - **不许静默改编码**。
3. **换行符**：CRLF / LF / CR 三态切换，状态栏可见。
4. **撤销重做**：栈无实际上限，各标签独立，10000 步不崩。
5. **查找替换**：`Ctrl+F` / `Ctrl+H`、大小写、全词、正则（`Ctrl+R`）、循环、范围（当前标签 / 所有标签）。**用底座已有正则引擎，不引入新库。**
6. **视图**：自动换行开关、行号、空白符显示、缩放、状态栏 5 段（行/列、选中字符数、字节数、编码、换行符）全部可点击。
7. **菜单**：编码与换行符直接放「文件」菜单下，两步可达。

### 验收
| 项 | 判据 |
| --- | --- |
| 编码样本 | 20 组样本全部正确识别（`docs/03` 七） |
| 乱码修复 | 一份 GBK 文件点「以 GB18030 重新解释」后正常显示，字节不变 |
| 有损保护 | 转 GBK 遇不可表示字符时弹窗列出前 20 处，不静默替换 |
| 撤销 | 连续 10000 步撤销/重做无崩溃、无内存暴涨 |
| 大字符 | 打开 10 万行的纯文本，滚动不卡、输入无延迟 |
| 零常驻 | M0 的三条达标项**仍然达标**（回归） |

---

## 四、M2 快

### 目标
大文件不卡，断电不丢。

### 任务
1. **大文件模式**：
   - >20MB 询问，>100MB 默认进入。
   - 视口 ±4MB 块窗口 + LRU 换入换出。
   - 块索引 `{偏移, 字节长度}` 后台增量构建。
   - 关闭全文索引（改为顺序扫描 + 进度 + 可取消）。
   - 关闭当前行装饰，改块级撤销，状态栏标注「大文件模式」。
   - **红线：窗口必须先出来，载入在后台，不许假死。**
2. **会话恢复**：默认关闭的勾选项；自动草稿 30 秒写 `%LOCALAPPDATA%\Chit\drafts\`，目录上限 16MB。
3. **深色模式**：跟随系统 + 手动三态。**只用系统语义色，不做自定义皮肤。**
4. 崩溃恢复：异常退出后重启能提示恢复草稿。

### 验收
| 项 | 判据 |
| --- | --- |
| 100MB 文件 | 窗口 **1 秒内出现**，可输入，滚动跟手 |
| 1GB 文件 | 能打开（只载视口），操作不崩溃 |
| 假死 | 全程无「未响应」白屏 |
| 崩溃恢复 | 强杀进程后重启，草稿可恢复；正常关闭后草稿自动清理 |
| 草稿上限 | drafts 目录不超 16MB，透明可见，可一键清空 |
| 回归 | 冷启动、体积、零常驻、零联网**仍达标** |

## 五、M3 集成

### 目标
双击一个 `.txt` 真的能用到它，同时绝不做流氓手段。

### 任务（详见 `docs/06`）
1. **注册为「打开方式」候选**：安装时写 HKCU 的 `Chit.TextFile` 与 `Applications\Chit.exe`，各扩展名加 `OpenWithProgids`。**只让 Chit 出现在候选里，不抢默认。**
2. **引导用户设默认**：`ShellExecuteW(L"ms-settings:defaultapps")` 或 `IApplicationAssociationRegistrationUI::LaunchAdvancedAssociationUI("Chit")`，并**如实告诉用户「Windows 不允许程序自己设默认，需要你点一下」**。
3. **单实例 + 参数转发**：已有实例则转发参数开新标签，新进程立刻退出。正确处理空格/中文/引号路径、多文件、文件不存在。
4. **拖拽打开**：支持从资源管理器拖文件进窗口。
5. **文件关联设置面板**：默认只勾 `.txt` 与 `.log`，其余由用户主动勾。
6. **卸载器**：精确回滚注册表（先判断值是不是我们写的），**不伪造恢复默认**，附验证脚本。

### 验收
| 项 | 判据 |
| --- | --- |
| 出现方式 | 右键 `.txt` → 打开方式里能看到 Chit |
| 默认设置 | 系统「默认应用」里能把 `.txt` 设为 Chit，设完双击真的打开 Chit |
| 单实例 | 双击第二个文件只在已有窗口开新标签，任务管理器只有一个 Chit |
| 路径 | 含空格、中文、引号的路径都能正确打开 |
| 无劫持 | notepad.exe 未被 IFEO 重定向；HKLM 与 HKEY_CLASSES_ROOT 未被写入；UserChoice Hash 未被伪造 |
| 卸载 | 运行 `docs/06` 的 5 条验证脚本，全部为空/不存在 |
| 回归 | 四条硬指标仍达标 |

**M3 是「是不是流氓软件」的最终考场。**

## 六、M4 交付

### 目标
能安安全全地给别人装，也能安安静静地卸干净。

### 任务
1. **安装包**：Inno Setup 或 NSIS（**选许可宽松的那个**），默认装 `C:\Program Files\Chit\`。
2. **首启**：不做欢迎页、不做向导、不做推广，直接开一个空白文档。
3. **卸载器**：`Program Files` 清理 + 注册表精确回滚 + 可选保留 `chit.ini`。
4. **绿色版**：约 1MB 免安装 zip，默认不写注册表，`chit.ini` 与 exe 同目录。
5. **说明文档**：README（用户向）+ 许可证 + 更新说明。
6. **发版前全量回归**：五条发版脚本全部跑一遍。

### 验收（发版五脚本，取自 `docs/04` 六）
```powershell
# 1. 后台占用：期望「无输出」
Get-Process -Name Chit

# 2. 空文档内存：期望私有工作集 ≤2MB，应用堆 ≤10KB
Get-Process -Name Chit | Select-Object WorkingSet64, PrivateMemorySize64

# 3. 冷启动：10 次取中位数，期望 ≤100ms
Measure-Command { Start-Process -FilePath "C:\Program Files\Chit\Chit.exe" -Wait }

# 4. 安装体积：期望 ≤3MB
(Get-ChildItem "C:\Program Files\Chit" -Recurse | Measure-Object -Property Length -Sum).Sum / 1MB

# 5. 零联网：防火墙 / Wireshark 挂一周，期望零记录
```

| 项 | 判据 |
| --- | --- |
| 安装包 | 体积 ≤1.5MB，安装过程无捆绑、无勾选陷阱 |
| 卸载 | 装完再卸，Program Files 与 HKCU 两个键全清 |
| 绿色版 | 解开即用，不写注册表，删除文件夹即卸载 |
| 首启 | **没有**欢迎页/向导/推广 |
| 全量回归 | 五条脚本全过 |

## 七、贯穿全程的三条红线

不管在哪个里程碑，下面三条**任何时刻都不许破**：

| 红线 | 违例判定 |
| --- | --- |
| **零常驻** | 关闭窗口后进程仍在（托盘/服务/后台线程/启动项） |
| **零联网** | 源码或二进制出现任何网络符号；构建期扫描未拦住 |
| **秒开** | 冷启动中位数 >100ms 且未在上一个里程碑修复 |

**如果某个新功能让这三条中任意一条破了，砍掉那个功能，不是放宽红线。**

---

## 八、超预算时的砍功能顺序

一旦工期或体积超标，按此顺序砍，**不许跳步**：

1. 砍可选功能：拼写检查 → 会话恢复 → 深色 → 语法高亮
2. 砍视觉装饰
3. 砍便利功能
4. **绝不砍：冷启动速度、文本模型正确性、零常驻。**

---

## 九、交付前自检清单

每个里程碑收尾时逐项打勾：

- [ ] 关闭窗口后 `Get-Process -Name Chit` 无输出
- [ ] 冷启动中位数 ≤100ms
- [ ] 安装目录 ≤3MB
- [ ] 源码搜不到 `socket` / `WSAStartup` / `WinINet` / `WinHTTP` / `UrlMon` / `curl`
- [ ] notepad.exe 未被 IFEO 重定向
- [ ] 未写 HKLM、未写 HKEY_CLASSES_ROOT、未伪造 UserChoice Hash
- [ ] 卸载后注册表与目录全清（M3 起）
- [ ] 打包产物是单文件 exe
- [ ] `licenses/` 下三份原文齐全
- [ ] 无 `git add` / `git commit` / `git push` 痕迹
- [ ] 界面截图看起来像一个系统附件，不像网页或 App
- [ ] 全中文界面，无英文残留
