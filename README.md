# Chit · 小方工作室极简纯文本编辑器

> **小方工作室 · 出品** ｜ 立项阶段规格 `v1.0` ｜ 2026-10-06
> 一句话：**一台电脑上最快的记事本。打开就在，关掉就没了，后台一点痕迹都不留。**

---

## 这是什么

Chit 是小方工作室产品线里**体量最小的一款**。它只做一件事：把纯文本打开、编辑、保存。

它存在的理由很具体——**让用户可以放心地把 Windows 记事本丢到一旁**。记事本太弱（没有多标签、没有编码切换、没有正则替换、没有大文件），而市面上够用的替代品又普遍臃肿（Notepad++ 装完几十 MB、挂 GPL 许可、还带插件生态和自动更新）。Chit 要占的位置是中间那一段：**比记事本强得多，比任何编辑器都轻得多。**

它不做 Markdown 排版、不做图片、不做语法高亮全家桶——那些是 **Scheda** 的活。Chit 只管纯文本，Scheda 管带格式的 Markdown 与图片，两者是一对，共用同一套「零常驻」哲学。

---

## 三条不妥协

### 1. 零常驻 —— 后台占用 = 0 KB

Chit 默认**不常驻**：关闭窗口 = 进程立刻完全退出。不驻留托盘、不注册服务、不装驱动、不开机自启、不留后台线程。

所以「挂在后台多少内存」这个问题的答案是 **0 KB**。不是「压到 10KB 以内」，是**根本不存在这个进程**。永久成立，不随版本变化，不随打开过的文本量变化。

用户想要的「挂后台没人注意到、开机自启完全没影响」，Chit 用「不常驻」这件事彻底满足——比常驻做得更绝。

> 若确实想要更快的热启动，可选开启「预热常驻」开关（默认关闭）。代价是私有工作集约 1.5 MB，热启动从 100 ms 降到 30 ms。**这是取舍，不是默认。** 详见 [docs/04](docs/04-资源占用预算.md)。

### 2. 零联网 —— 不是流氓软件

用户点名要求：**「它绝对不能是流氓软件。」** 这一条写在架构里，不是写在宣传语里。

- 不联网。整个程序没有一行网络代码。没有遥测、没有崩溃上报、没有使用统计。
- 不自动更新。装了什么版本就是什么版本，永不静默替换、永不后台下载。
- 不捆绑。安装包里只有 Chit 自己，没有推荐软件、没有工具栏、没有「优化大师」。
- 不劫持系统。**不偷偷改写 `notepad.exe`**，不改系统文件，不加系统级右键菜单。
- 可干净卸载。卸载后删除文件关联、把默认程序还给用户原来的选择、不残留注册表项。
- 安装后可以正常右键卸载，没有「卸载残留」这种设计。

文件关联这件事本身是合规的：注册 ProgID 让 Chit 出现在「打开方式」里，再引导用户到 Windows 自带的「默认应用」页面点一下。**用系统给的官方路径拿默认权，不靠技术手段硬抢。** 详见 [docs/06](docs/06-文件关联与系统集成.md)。

### 3. 秒开 —— 冷启动 < 100 ms

原生 Win32 程序，无 Electron、无 Tauri、无 WebView、无 .NET、无 JIT 预热。双击到可以打字，目标 100 毫秒以内。

因为它不常驻，所以「秒开」这件事必须靠冷启动速度硬扛，而不是靠预热进程——这是 Chit 的整个技术选型围绕的唯一目标。

## 硬指标

| 指标 | 目标 | 备注 |
| --- | --- | --- |
| **后台占用（默认）** | **0 KB** | 不常驻，进程不存在 |
| 应用自身堆分配（空文档） | ≤ 10 KB | 不含 OS 映射的 DLL 与线程栈 |
| 磁盘占用（安装后） | ≤ 3 MB | 比清单里的 5 MB 更严 |
| 冷启动到可输入 | ≤ 100 ms | 原生 Win32 |
| 进程私有工作集（空文档、窗口开着） | ≤ 2 MB | 原生进程的物理基线 |
| 联网行为 | 0 | 一行网络代码都没有 |
| 自启动项 | 0 | 默认不写任何启动项 |
