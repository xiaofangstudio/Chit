## 🆚 它站在哪

Chit 是小方工作室产品线里**体量最小的一款**，只做一件事：把纯文本打开、编辑、保存。

它要占的位置很明确——**比记事本强得多，比任何编辑器都轻得多**。Notepad++ 装完几十 MB、挂 GPL、还带插件生态和自动更新；Chit 安装后磁盘占用 ≤ 3 MB。

它不做 Markdown 排版、不做图片、不做语法高亮全家桶——那些是 **Scheda** 的活。Chit 只管纯文本，Scheda 管带格式的 Markdown 与图片，两者是一对，共用同一套「零常驻」哲学。

## 🔒 三条不妥协

### 1️⃣ 零常驻 —— 后台占用 = 0 KB

关闭窗口 = 进程**立刻完全退出**。不驻留托盘、不注册服务、不装驱动、不开机自启、不留后台线程。

「挂后台多少内存」的答案是 **0 KB**——不是「压到 10KB 以内」，是**根本不存在这个进程**。永久成立，不随版本变化，不随打开过的文本量变化。

> 若确实想要更快的热启动，可选开启「预热常驻」开关（默认关闭）。代价是私有工作集约 1.5 MB，热启动从 100 ms 降到 30 ms。**这是取舍，不是默认。**

### 2️⃣ 零联网 —— 不是流氓软件

这一条写在架构里，不是写在宣传语里：

- ❌ 不联网——没有遥测、没有崩溃上报、没有使用统计
- ❌ 不自动更新——装了什么版本就是什么版本，永不静默替换
- ❌ 不捆绑——安装包里只有 Chit 自己，没有推荐软件、没有「优化大师」
- ❌ 不劫持系统——不偷偷改写 `notepad.exe`，不改系统文件，不加系统级右键菜单
- ✅ 可干净卸载——删文件关联、还原默认程序、不残留注册表项

### 3️⃣ 秒开 —— 冷启动 < 100 ms

原生 Win32，无 Electron、无 Tauri、无 WebView、无 .NET、无 JIT 预热。因为它不常驻，「秒开」必须靠冷启动速度硬扛，而不是靠预热进程——这是 Chit 整个技术选型围绕的唯一目标。

## ❓ 常见问题

**什么时候能用上？**
立项规格已定稿，工程起点是把 BSD-3-Clause 的 Notepad4 底座 clone 下来改造，而不是从零搭骨架。进展看仓库动态。

**为什么磁盘能压到 3 MB？**
原生程序 + 不带运行时 + 只做纯文本。功能越克制，体积越小。

**会支持 Markdown 吗？**
不会。那是 Scheda 的事，Chit 只管纯文本。
